# ҚТР-2 ЛАОГ — Субкомпонентлар мониторинг платформаси

«Қишлоқ тадбиркорлигини ривожлантириш — 2 фаза» (UZ-7061, Жаҳон банки) лойиҳасини
амалга ошириш гуруҳи (ЛАОГ) учун барча субкомпонентларни ягона жойдан назорат
қилиш платформаси.

## Очиш

`index.html` файлини исталган браузерда очинг — сервер, интернет, ўрнатиш керак эмас.
Телефонда ҳам тўлиқ мослашади. Чоп этиш (Ctrl+P) — тақдимот тарқатмаси учун.

## Модуллар

| Модул | Мазмуни |
|---|---|
| Бошқарув панели | KPI, даврлар план/факт, округлар кесими, огоҳлантиришлар |
| Субкомпонентлар | 1.2, 1.4, БИММ — мақсад, ижрочи, босқич |
| 1.4 Аёллар дастури | 5 давр, тренинглар журнали (MIS 24-соат қоидаси), грантлар |
| 1.2 Сотиш занжирлари | 17 соҳа pipeline: сўровнома → таҳлил → тавсия → кўргазма → агрегатор |
| Шартномалар | BPO×4, CMP (36 ой), консультант — deliverable назорати |
| Ҳудудлар | 9 ҳудуд, 20 туман, 4 округ кесими |
| Ҳисоботлар | CMP ойлиги (5-санагача), БТҚБТ якунийси — кечикканлар қизил |
| Огоҳлантиришлар | Автоматик қоидалар (R1–R5) + қўлда киритиш |
| Киритиш | Тренинг/грант/огоҳлантириш формалари → localStorage, JSON экспорт |

## Маълумотлар

Демо рақамлар ТЗ (TOR) ҳужжатларидаги параметрларга мос: 10 000 аёл, 1 000 грант,
$5к/$15к лимитлар, 20 туман, 200 маҳалла, 120 соат ўқитиш ва ҳ.к.
Киритилган янги ёзувлар браузернинг localStorage'ида сақланади.
